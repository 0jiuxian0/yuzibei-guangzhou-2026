# 于梓贝「夏日出逃之必要」广州站 · 观演信息页

静态站点，汇总广州双场购票、观演指南、歌单与社媒链接。

## 在线访问

https://0jiuxian0.github.io/yuzibei-guangzhou-2026/

（需在 GitHub 仓库 Settings → Pages 中启用 **Deploy from a branch · main · / (root)**）

## 本地预览

直接用浏览器打开 `index.html`，或在仓库根目录执行：

```powershell
python -m http.server 8080
```

然后访问 http://localhost:8080
